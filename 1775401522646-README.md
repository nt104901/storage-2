# GitHub File Storage

Автоматическая система хранения файлов в GitHub с ротацией репозиториев.

## 🚀 Возможности

- Автоматическая загрузка файлов в GitHub
- Автоматическое создание репозиториев `storage-1`, `storage-2`, и т.д.
- Ротация репозиториев при достижении 1 ГБ
- Получение прямых ссылок на файлы
- Статистика использования репозиториев

## 📋 Установка

1. Установите зависимости:
```bash
npm install
```

2. Настройте [`server.js`](server.js:12):
```javascript
const GITHUB_OWNER = 'ваш-username'; // Ваш GitHub username
```

3. Запустите сервер:
```bash
npm start
```

4. Откройте браузер: http://localhost:3000

## 🔧 Как это работает

1. Вы загружаете файл через веб-интерфейс
2. Сервер проверяет размер текущего репозитория `storage-N`
3. Если размер < 1 ГБ - файл загружается туда
4. Если размер >= 1 ГБ - создаётся новый репозиторий `storage-N+1`
5. Вы получаете прямую ссылку на файл

## 🔒 Безопасность

- GitHub токен хранится только на сервере
- Токен не передаётся клиенту
- Все запросы к GitHub API идут через сервер

## ⚙️ Настройки

В [`server.js`](server.js:11):

```javascript
const GITHUB_TOKEN = 'ваш_токен';        // GitHub токен
const GITHUB_OWNER = 'ваш_username';     // GitHub username
const REPO_PREFIX = 'storage-';          // Префикс репозиториев
const MAX_REPO_SIZE = 1024 * 1024 * 1024; // 1 ГБ
const PORT = 3000;                       // Порт сервера
```

## 📊 API

### POST /api/upload
Загрузка файла

**Параметры:**
- `file` - файл (multipart/form-data)

**Ответ:**
```json
{
  "success": true,
  "url": "https://github.com/user/storage-1/blob/main/files/123456-file.txt",
  "downloadUrl": "https://raw.githubusercontent.com/...",
  "repo": "storage-1",
  "fileName": "123456-file.txt",
  "size": 1024
}
```

### GET /api/stats
Статистика репозиториев

**Ответ:**
```json
{
  "stats": [
    {
      "repo": "storage-1",
      "size": 536870912,
      "sizeMB": "512.00",
      "percentage": "50.0"
    }
  ]
}
```

## 💡 Примеры использования

1. Загрузите файл через веб-интерфейс
2. Скопируйте полученную ссылку
3. Используйте её где угодно для доступа к файлу

## ⚠️ Важно

- Токен должен иметь права `repo` и `public_repo`
- Репозитории создаются публичными
- Максимальный размер файла через GitHub API: 100 МБ
