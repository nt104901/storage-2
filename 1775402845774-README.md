# 💳 Система приёма платежей через DonationAlerts

Сайт для приёма платежей с поддержкой СБП и карт мира через DonationAlerts.

## 🚀 Установка и запуск

```bash
npm install
npm start
```

Сервер запустится на `http://localhost:3000`

## 📋 Использование

### Админка
Перейдите на `http://localhost:3000/admin`

1. Введите сумму платежа
2. Добавьте описание (опционально)
3. Нажмите "Создать платёж"
4. Скопируйте ссылку и отправьте пользователю

### Страница платежа
Пользователь переходит по ссылке вида: `http://localhost:3000/payment/1234567890`

1. Видит сумму платежа
2. Выбирает способ оплаты (СБП + Карты мира)
3. Нажимает "Оплатить"
4. Перенаправляется на DonationAlerts для завершения платежа

## 🔧 API Endpoints

### Создание платежа
```
POST /api/admin/create-payment
Content-Type: application/json

{
  "amount": 100,
  "description": "Описание платежа"
}

Response:
{
  "success": true,
  "paymentId": 1234567890,
  "paymentLink": "http://localhost:3000/payment/1234567890",
  "amount": 100,
  "description": "Описание платежа"
}
```

### Получение информации о платеже
```
GET /api/payment/:paymentId

Response:
{
  "id": 1234567890,
  "amount": 100,
  "description": "Описание платежа",
  "status": "pending",
  "createdAt": "2026-04-05T00:24:43.925Z",
  "paymentLink": "http://localhost:3000/payment/1234567890"
}
```

### Обработка СБП платежа
```
POST /api/payment/:paymentId/sbp

Response:
{
  "success": true,
  "url": "https://www.donationalerts.com/payin/pw?client_id=...",
  "paymentId": 1234567890
}
```

### Проверка статуса платежа
```
GET /api/payment/:paymentId/status

Response:
{
  "paymentId": 1234567890,
  "status": "pending|processing|completed",
  "amount": 100,
  "description": "Описание платежа",
  "createdAt": "2026-04-05T00:24:43.925Z",
  "processedAt": "2026-04-05T00:25:00.000Z"
}
```

## 🎨 Технологии

- **Backend**: Node.js + Express
- **Frontend**: Vue 3 (CDN)
- **HTTP Client**: Axios
- **Платежи**: DonationAlerts API

## 📝 Конфигурация

Отредактируйте `.env` файл:

```
PORT=3000
BASE_URL=http://localhost:3000
NODE_ENV=development
```

## 🔐 Безопасность

Для production:
1. Используйте HTTPS
2. Добавьте аутентификацию в админку
3. Используйте реальную БД вместо Map
4. Добавьте валидацию и санитизацию входных данных
5. Реализуйте webhook для подтверждения платежей
